# 一期验收记录

[English](phase-1.md) | 中文

本记录区分功能验收和外部生产集成。实现运行在固定的官方 Harness 源码上，使用其真实模型、会话与执行服务。证据标识见[结构化记录](phase-1-evidence.json)。

<a id="scope"></a>
## 交付范围

本地工作台提供六阶段与 31 个节点、对话需求草稿、需求修订、入版、并行人工评审和冻结基线。开发明确选择本地工作区，使用限定范围的 AI 文件工具、查看差异并执行本地检查。不可变提测批次、用例、缺陷回归、独立 UAT、外部发布记录、回流需求和范围变更使用同一认证工作流。

<a id="live"></a>
## 实际试运行证据

本地项目名为“AI 研发一期验收”。产品、研发和测试操作使用独立本地账号。每条审批均标记隔离测试，不代表真实业务审批。

1. 真实 DeepSeek 对话生成结构化版本号格式化需求。浏览器编辑并保存草稿到版本。首次模型配置错误明确显示，修正后重试成功。
2. 需求与设计材料通过评审后形成基线 B1。开发绑定独立本地 Git 工作区。AI 读取并修改源码，保留既有测试；本地 npm 检查产生已保存报告。
3. 第一个实际候选已提交并打包。测试复现真实缺陷：带抛异常转换钩子的非法对象产生 Error，而非需求要求的 TypeError。测试批次失败并退回开发。
4. AI 修复错误消息构造。新增回归文件在三个参数位覆盖三类特殊对象。第二个候选通过三个测试组，其中包含九组转换检查，并完成提交与打包。
5. 开发阶段变更新增明确回归标准。批准后暂停任务，保留 B1 和未受影响的产品评审，重新完成技术与测试评审后形成 B2。测试阶段变更被驳回，活动批次保持不变。
6. 第二次提测使用新干净提交及其专属评审证据。测试在新批次验证缺陷并完成测试准出，随后由产品独立完成 UAT。
7. 实际候选压缩包被复制、解包到隔离的灰度与全量目录，再从这些文件执行测试。工作流记录本地演练、反馈、复盘和知识后关闭版本。没有部署生产服务。

<a id="checks"></a>
## 自动化与浏览器检查

工作流、运行时和客户端定向测试共 15 个文件、33 项通过。主机与客户端 TypeScript 及完整本地 Web 构建通过，定向 lint 通过。测试覆盖持久化、角色伪造、乐观修订、幂等、过期草稿、不可变基线、候选不匹配、缺陷回归、UAT 驳回、关闭发布状态和工作区切换。

新增无密钥会话回放测试也已通过：`pnpm run test:rd:integration` 通过正式启动器装配 Harness，重放真实 DeepSeek 会话中的两个模型调用，核对产物内容与原记录一致，再保存需求到版本并读取同一会话。运行前需完成 `pnpm run build:rd`。

独立最终审查发现五项重要问题。修复前通过回归用例复现：候选专属审批、技术材料修改、工作区重新绑定、UAT 驳回恢复，以及关闭后发布。修复后这五项定向回归均通过。

较广的上游 GUI 测试有 9,780 项通过、1 项跳过，首次出现 5 项失败。其中 3 项工作台主题问题已修复并通过定向复跑。另有 2 个未修改的上游用例单独复跑仍失败：PDF 冒烟缺少可选原生 canvas 绑定，trajectory bundle 未注册预期标签。本记录不宣称完整上游 GUI 或 CI 全绿。

浏览器验收使用实际装配工作台，完成版本创建、真实 AI 草稿、产物保存、角色登录、开发对话、源码修改与本地检查。业务 API 验收使用同一认证远程方法完成评审、提测、缺陷关闭、变更及发布记录，没有以静态截图代替实现。

2026-10-04 的最终浏览器检查验证了 1440px 和 960px 双栏、720px 无横向溢出的单栏、明暗主题可读性、专注模式恢复、切换上下文和刷新后的独立草稿恢复，以及最新回复自动滚动。窄屏对话固定输入区高度，长记录在内部滚动。实际截图：[工作台](../../output/acceptance/phase-1-workbench.jpg)、[窄屏布局](../../output/acceptance/phase-1-narrow.jpg)、[深色主题](../../output/acceptance/phase-1-dark.jpg)。临时浏览器尺寸与主题已恢复，客户端文字归属和 TypeScript 路径检查通过。

<a id="limitations"></a>
## 剩余边界

- 本期未实现或验证生产发布、外部 CR/CI 系统、远程执行主机、企业身份与多项目协作。
- 历史验收数据保留。变更后发现的显示问题使首个已关闭样例的任务计划节点仍待处理；新的工作区确认会刷新该派生节点，已有回归测试。后续实际复验版本“v0.1.1 · 主线复验”已完成两个基线、31/31 节点全部通过，标识见结构化记录。
- 完整文档检查尚未全绿：原有五份中文设计稿与计划缺少英文配对，两份原稿存在硬换行；上游引用检查禁止真实提交哈希，与本次保留精确源码基线的记录相冲突。原稿与基线保留，新包文档、双语操作手册及 README 规范检查通过。
- 本地交付未重跑完整上游录制会话语料与 CI 矩阵。真实模型调用、本地文件效果、领域集成测试与装配后浏览器验收分别记录如上。

启动与恢复见[试运行指南](../operations/ai-rd-pilot.zh.md)。二期仍为原定的自动化与企业集成待办。
